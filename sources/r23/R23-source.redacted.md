## 开始测试

先结束旧对话，等完全退出后重新唤起小可。先说一句普通聊天，确认麦克风、扬声器正常，再开始测试。不要清除应用数据或重新刷机。

天气在后台查，查的过程中可以继续聊天；结果应在合适的空闲时机补播。听到等待词不等于查询成功，收到服务端记录也不等于真人实际听到。

## 可照着说

| 用例 | 话术／步骤 | 预期 |
|---|---|---|
| 本地天气 | “今天这里下不下雨？” | 按网络定位的大致城市回答天气。不是把“下”当作城市；不能确定地点或资料时明确说明。 |
| 复合问题 | “帮我查今天这里下不下雨，放学适合打球吗？” | 至少给出可靠的大致天气，不把后半句当成地名。不要求专业运动或逐小时预测。 |
| 查询时聊天 | 查询后马上说“我今天画了一只小猫” | 正常接着聊天，不能必须等天气查完才回。天气有结果后在空闲时机补播。 |
| 改查 | “帮我查北京今天的天气”，随后“改查成都今天的天气” | 按新城市查；不能把已取消的旧城市结果当成新结果播报。 |
| 体育 | “帮我查羽毛球双打发球的后发球线是哪条？” | 有可靠资料时给简短解释；记录识别是否完整、是否回答了发球界线，而非泛泛讲战术。 |
| 游戏 | “帮我查我的世界最近的正式更新” | 有可靠来源时简单回答；没有符合时效的资料就明确说明，不编最新版本。 |
| 科普 | “帮我查恐龙为什么会灭绝” | 简短有据的解释。接着问“那火山有什么影响”，观察是否自然衔接。 |
| 取消、插话 | 查询后说“不用查了，我们聊别的”；播报中说“停一下” | 取消后不继续返回旧任务；插话后让出声音。 |
| 退出再进入 | 查询完成或播报中退出对话，再进入，说“继续刚才的搜索结果” | 有可恢复记录时续讲；没有可恢复记录时明确说明，不能装作已有结果。此项保留回归观察，不能凭服务端发送记录认定真机通过。 |
| 普通聊天 | 不发起搜索，聊小猫、篮球、动漫各一句；与其他内测机对比 | 不应明显变慢或不回复。感觉迟缓时记录秒数，不只写“卡”。 |

首次体验重点看本地天气、查询时聊天、改查、普通聊天。其他用例不要求一口气完成。
