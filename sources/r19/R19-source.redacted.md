## 先做这八项（约15–25分钟）

请一次只提一个明确问题，先按原话测试，再自由追问。每项记开始时间到秒、实际听到的话和是否完整；听不到、答非所问、仅说“我查查”后不返回都记为问题。

| 编号／目的 | 可照着说或操作 | 预期表现与观察重点 |
|---|---|---|
| A 普通聊天速度 | “我今天打球赢了一次。”再说“我喜欢皮卡丘。” | 自然接话，不无故搜索；重点记有没有比平时明显慢、丢首词、长时间静音。可用另一台P1设备同环境对比。 |
| B 搜索时继续聊天 | “帮我查一下我的世界基岩版最近正式更新了什么。”听到查找衔接词后马上说“我今天打球赢了一次。” | 先正常回应赢球，不被搜索堵住；空闲后补充搜索结果。版本和发布日期应明确；无法确认最新时如实说明，不把某次旧公告说成最新。 |
| C 空闲补播／运动 | “羽毛球双打发球后面的线到底算哪条？帮我查查。”然后安静等候。 | 衔接词后返回与双打发球边界直接相关的答案，不能换成其他运动或只泛谈规则。超过30秒仍没有结果或明确失败说明，记录为异常，不连喊多次。 |
| D 插话与续讲 | “帮我查一下恐龙为什么会灭绝。”结果播到一半说“停一下，我先说一句，我今天看了一本科普书。”对话结束后说“继续刚才的搜索结果。” | 插话后停止或让出播报并接话；续讲恢复原结果，不重新查询，不无故说没有结果。尚未说完的一句话可能从句首重说，应记录具体重复范围。 |
| E 取消 | “帮我查一下宝可梦地平线的主角是谁，不要剧透。”听到查找衔接词后说“不用查了，我们聊别的。” | 取消后正常聊天，不再冒出被取消结果。取消确认词可能被后一句打断，以不继续播旧结果为准。 |
| F 改查 | “帮我查一下中国最近的航天新闻。”搜索期间说“改查大鱼海棠里大鱼这首歌是谁唱的。” | 返回后一个问题，不插入已替换的航天结果；不把电影里的另一首歌认作《大鱼》。 |
| G 退出重连（重点） | “帮我查一下恐龙为什么会灭绝。”等结果开始播放，听2–3秒就退出聊天；1分钟内重新进入，先静默10秒，再说“继续刚才的搜索结果。” | 新会话先不自行抢播；明确续讲后接回刚才结果，不重新查、不无故说没有记录。记录退出、重进、续讲话术三个时间。请在短时间内完成，本次不承诺跨天找回或服务重启后恢复。 |
| H 自由追问 | 对C的回答接着说“那我发到那条线外面一点，是不是就出界了？” | 听懂正在聊的主题，回答相关；若信息不足应说明或追问，不能把新问题当成“继续播放”而机械重播原答案。 |

## 兴趣题库（任选4–6题，避免只查天气）

| 话题 | 话术 | 重点 |
|---|---|---|
| 游戏玩法 | “帮我查一下，我的世界里的红石中继器主要有什么用？” | 能解释实际用途，区分游戏版本；不凭空捏造更新。 |
| 动漫 | “帮我查一下宝可梦地平线的主角是谁，不要剧透。” | 对准《地平线》，不把其他篇章主角混进来，不主动泄露剧情。 |
| 音乐 | “帮我查一下，大鱼海棠里大鱼是谁唱的？” | 人名、曲名对应，必要时纠正主题曲／印象曲称呼。 |
| 宠物 | “猫咪一直呼噜呼噜，是不是肯定很开心？帮我查查。” | 不绝对化，能解释多种可能；不把检索当兽医诊断。 |
| 航天 | “帮我查一下中国最近的航天新闻，讲一条就好。” | 说清报道日期与事件，旧回顾不能冒称今天；注意“上周”到底以哪天为准。 |
| 官方正文 | “帮我查我的世界官网关于草床的介绍，看看它会不会改变重生点。” | 有资料时回答核心用途。网站打不开或只得到摘要时说明范围，不声称读完全文。 |
| 朋友相处 | “同学总笑我玩的游戏幼稚，我有点不开心。” | 自然聊天，不自动上网搜索，语气平等、不说教。 |
| 游戏创意 | “我想在游戏里造一个树屋，你陪我想想怎么设计。” | 能聊想法，不因出现游戏名就机械查资料。 |

查不到、来源失效可以如实说明，但这类结果应填“部分通过／未满足”，不能把所有“无法确认”都当成搜索体验通过。当前正文抓取偶尔失败、最新资料不完整仍是已知边界。
