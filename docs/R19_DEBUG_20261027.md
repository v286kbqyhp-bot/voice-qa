4. 复测通过仍保留首次未通过；复测结果单列。
5. 自动继续下一条独立用例；依赖失败用例的场景标为未满足前置，不强行运行。
6. 缺素材/能力的开测前阻塞不当作产品失败，也不盲目重复；已执行但无判定器的用例保持待复核。
7. 用户停止立即结束队列，不再复测或继续。
