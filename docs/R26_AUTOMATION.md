# R26 用例、停止边界与证据

来源：`sources/r26/manifest.json`，原文10组、反馈6字段。本轮现场367/尾号00100004；云端发布版本仅据用户提供回执。原文完整SN仅留本机来源和转发稿，仓库脱敏。

`cases/r26/` 将10组拆成11个YAML（第10组的科普展、航天消息分开）。`plans/r26/catalog.yaml` 是目录，不是自动suite；本轮由Agent逐项串行执行，保留原失败和一次独立诊断，并在重复连接异常后停止。现有 `run-suite` 固定继续独立用例，不提供本轮异常停止策略，不能直接拿目录启动无人值守批次。

准备入口仍为 `qa.py validate <case.yaml>`、`qa.py library-sync cases/r26`、`qa.py library-prepare <case.yaml> --output <new-local-directory>`；执行用 live + 本机配置 + prepared-assets，录音ASR使用 `docs/RECORDED_AUDIO_ASR.md`。Mac路径/音频编号不作为其他环境配置。

本轮实际执行第1组一次、第2/3组各两次、第4组一次；第4组未过input_ready，查询和改查均未播；第5—10组未运行。后续不沿用原结果当R26通过，不自动重试；恢复条件与设备/版本/网络须重新核验。第9组需要用户在场观察，升降须先确认机构无遮挡，禁止仅据命令日志判实体动作通过。

搜索等待以当前trace的worker查询提示调度，不能把短控制词文件播完当作端侧已识别；正文打断仅使用字幕+活动代理，尚未真机执行第6/7组。第7组计划重进后静默1.5秒（客户端约5秒闲置关房），再明确续讲；该选择不是已测结果。所有未执行档案明确未验收。

已执行6次均取得有效麦克风WAV、脱敏设备日志、步骤及独立ASR，原始包封存不回写。ASR未使用预期答案或设备字幕提示，不做说话人分离或校准置信度；同音字保留。Git只保存每次摘要与ASR指纹，真实证据在本机 `runs/<id>` 和 `.local/r26/asr/<id>.json`。

反馈：`docs/P003_SEARCH_R26_TEST_FEEDBACK_20261030.md`，10×6字段均填，其中未测不冒充已执行。本机转发稿为桌面同名文件，记录完整SN并附现有截图；截图主要为观察结束/退出前后，未取得每个异常瞬间的录屏。正常聊天的可听时延约2.8秒仅是两句本机样本，不是跨设备或真人感受结论。
